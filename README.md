# Student Performance Calculator with JUnit Testing

## Overview

This project is a simple Java application that calculates student academic performance based on assessment scores.

## Diagrame
<img width="600" height="700" alt="image" src="https://github.com/user-attachments/assets/15ba966a-7e2e-4efc-bd5f-0239fd430906" />




The system:
- Calculates the average mark
- Determines pass or fail status
- Classifies student performance
- Validates input values
- Includes automated unit testing using JUnit 5

## Technologies Used

- Java
- JUnit 5
- IntelliJ IDEA

## Features

- Grade calculation
- Performance classification
- Input validation
- Automated unit tests
- Boundary value testing

## Example

Score: 75
Result: Grade A

Score: 62
Result: Grade B

Score: 45
Result: Fail

## Testing

The project includes JUnit test cases that verify:

- Grade A classification
- Grade B classification
- Grade C classification
- Fail classification

All tests pass successfully, demonstrating that the calculation logic behaves as expected.
